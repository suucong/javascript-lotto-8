# 🍀 로또

## 기능 구현 목록

### 1. 로또 구입금액 입력 및 처리

- [x] 로또 구입 금액을 입력받는다.
  - [x] ❌ 숫자를 입력하지 않은 경우 &rarr; `[ERROR] 로또 구입 금액은 숫자 형식이어야 합니다.`
  - [x] ❌ 0 이하의 금액을 입력한 경우 &rarr; `[ERROR] 로또 구입 금액은 1000원 이상이어야 합니다.`
  - [x] ❌ 금액이 1,000원으로 나누어 떨어지지 않는 경우 &rarr; `[ERROR] 로또 구입 금액은 1,000원 단위어야 합니다.`
- [x] 사용자가 잘못된 값을 입력한 경우 `[ERROR]` 메시지를 출력하고 해당 입력 지점부터 다시 입력을 받는다.

### 2. 로또 발행 및 출력

- [x] 구입 금액에 맞춰 로또 가격(1,000원)으로 나누어 로또 발행 수량을 계산한다.
- [x] 계산된 수량만큼 1~45 사이의 **중복되지 않는** 6개의 숫자로 로또를 발행한다.
- [x] 발생한 로또 수량 및 번호를 **오름차순**으로 정렬하여 출력한다.

### 3. 당첨 번호 입력 및 처리

- [x] 당첨 번호 6개를 쉼표(,)를 기준으로 입력받는다.
  - [x] ❌ 입력받은 당첨 번호가 6개의 숫자가 아닌 경우 → `[ERROR] 당첨 번호는 6개여야 합니다.`
  - [x] ❌ 숫자와 구분자 이외의 다른 문자를 입력한 경우 → `[ERROR] 당첨 번호는 쉼표(,)로 구분된 숫자만 허용됩니다.`
  - [x] ❌ 1~45 범위를 벗어난 값을 입력한 경우 → `[ERROR] 당첨 번호는 1부터 45 사이의 숫자여야 합니다.`
  - [x] ❌ 당첨 번호에 중복된 숫자가 포함된 경우 → `[ERROR] 당첨 번호는 중복되지 않아야 합니다.`
- [x] 사용자가 잘못된 값을 입력한 경우 `[ERROR]` 메시지를 출력하고 해당 입력 지점부터 다시 입력을 받는다.

### 4. 보너스 번호 입력 및 처리

- [x] 보너스 번호 1개를 입력받는다.
  - [x] ❌ 숫자가 아닌 다른 값을 입력한 경우 → `[ERROR] 보너스 번호는 숫자 1개만 입력해야 합니다.`
  - [x] ❌ 1~45 범위를 벗어난 값을 입력한 경우 → `[ERROR] 보너스 번호는 1부터 45 사이의 숫자여야 합니다.`
  - [x] ❌ 보너스 번호가 직전에 입력된 당첨 번호 6개에 포함된 경우 → `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`
- [x] 사용자가 잘못된 값을 입력한 경우 `[ERROR]` 메시지를 출력하고 해당 입력 지점부터 다시 입력을 받는다.

### 5. 로또 당첨 확인 및 결과 출력

- [ ] 구매한 로또와 당첨 번호 및 보너스 번호 1개를 비교하여 당첨 여부를 확인한다.
- [ ] 일치 개수 및 보너스 일치 여부를 기반으로 **당첨 등수를 결정**하는 기능을 구현한다.
- [ ] 당첨 결과를 등수별 개수로 집계한다.
- [ ] 총 상금과 수익률을 계산한다.
- [ ] 수익률은 소수점 둘째 자리에서 반올림하여 처리한다.
- [ ] 당첨 통계와 총 수익률을 요구 사항 형식에 맞춰 출력한다.

<summary><h2 style="display: inline-block;">로또 기능 요구 사항</h2></summary>
<div markdown="1">

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.

<summary><h3 style="display: inline-block;">입출력 요구 사항</h3></summary>
<div markdown="1">

### 입력

- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

  ```
  14000
  ```

- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

  ```
  1,2,3,4,5,6
  ```

- 보너스 번호를 입력받는다.

  ```
  7
  ```

### 츌력

- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

  ```
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  [7, 11, 16, 35, 36, 44]
  [1, 8, 11, 31, 41, 42]
  [13, 14, 16, 38, 42, 45]
  [7, 11, 30, 40, 42, 43]
  [2, 13, 22, 32, 38, 45]
  [1, 3, 5, 14, 22, 45]
  ```

- 당첨 내역을 출력한다.

  ```
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  ```

- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

  ```
  총 수익률은 62.5%입니다.
  ```

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.

  ```
  [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
  ```

<summary><h2 style="display: inline-block;">프로그래밍 요구 사항</h2></summary>
<div markdown="1">

- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
  - 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- else를 지양한다.

  - 때로는 if/else, when문을 사용하는 것이 더 깔끔해 보일 수 있다. 어느 경우에 쓰는 것이 적절할지 스스로 고민해 본다.
  - 힌트: if 조건절에서 값을 return하는 방식으로 구현하면 else를 사용하지 않아도 된다.

- 구현한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.out, System.in, Scanner) 로직은 제외한다.

  - 단위 테스트 작성이 익숙하지 않다면 `LottoTest`를 참고하여 학습한 후 테스트를 작성한다.

### Lotto 클래스

- 제공된 `Lotto` 클래스를 사용하여 구현해야 한다.
- `Lotto`에 `numbers` 이외의 필드(인스턴스 변수)를 추가할 수 없다.
- `numbers`의 접근 제어자인 `#`은 변경할 수 없다.
- `Lotto`의 패키지를 변경할 수 있다.

```
class Lotto {
  #numbers;

  constructor(numbers) {
    this.#validate(numbers);
    this.#numbers = numbers;
  }

  #validate(numbers) {
    if (numbers.length !== 6) {
      throw new Error("[ERROR] 로또 번호는 6개여야 합니다.");
    }
  }

}
```
